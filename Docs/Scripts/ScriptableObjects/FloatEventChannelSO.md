# FloatEventChannelSO

`Assets/_Scripts/ScriptableObjects/FloatEventChannelSO.cs`

Variante de [VoidEventChannelSO](VoidEventChannelSO.md) pensada para eventos con payload `float` (nombre y `menuName` lo indican), pero la implementación actual todavía usa `UnityAction` sin parámetro — el tipo `float` no está cableado en `RaiseEvent()`. No tiene ninguna referencia de uso en el proyecto todavía.
